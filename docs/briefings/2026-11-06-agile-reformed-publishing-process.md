# "Agile, Reformed": how it went from issue to Substack draft

_Briefing written 2026-11-06 from 4 astern sessions (2026-10-08 to 2026-10-31), the issue thread [thorwhalen/essays#31](https://github.com/thorwhalen/essays/issues/31), two crowsnest ledgers and the audio work folder. Session ids are the first 8 characters. Almost everything happened in one session, `0902065b` (named reverse_centaurs_revisited, cwd t/essays), which spawned fixer sessions for tool gaps._

## The process actually followed

1. **Seed and brief (2026-10-08, `0902065b`).** The user pasted a long brief in the session: required verbatim opening ("Agility reminds me of a religion that has one denomination per individual..."), a witty line about the "big bad wolf" of process-led development in the style of David Foster Wallace, core themes (pros of heavy design, why agile rejected it, the AI shift), a personal story about design docs becoming "quadratically cheaper", and a conclusion about "ideas engineering". The user said explicitly: do deep research first, then write; hyperlink the sources in the essay (no Vancouver reference section in the essay itself); keep research notes in `docs/<working title>/`; post the first draft in the issue body, research, then propose a second "ready to publish" draft in the issue; use fleet tools for images and make generated images avoid the "AI slop" look; say whether Substack or Medium is best and which tools exist to semi-automate publishing.
2. **Draft v0 in the issue body (`0902065b`, 2026-10-08).** The essay text lived first in the body of issue #31 (not a comment). Draft v0 was checked with `acquaint style-lint` (via the deslop skill) before posting.
3. **Research (`0902065b`, 2026-10-08).** The `do-research` skill; five parallel research agents produced Vancouver-referenced reports in `docs/The Agile Religion and the Agentic Reformation/`: history and semantics of agile, the case for upfront design, the documentation tax, agents and specifications, publishing (Substack vs Medium). Findings that changed the text: Royce wanted more documentation, "waterfall" was coined later by Bell and Thayer, the 100x cost-of-change figure was dropped, "worse than useless docs" softened, METR perception gap and the ETH Zurich AGENTS.md study added, prior art credited.
4. **Draft v1 "ready to publish" (issue #31, first comment; essay.md via PRs #32 and #33).** Hyperlinks to the original sources, 8 captioned images, one footnote. The Substack-ready source is `essay.md` in the research folder, with relative image paths and (from #33) front matter holding `title` and `subtitle` for Substack's subtitle field. The issue comment version used absolute raw.githubusercontent image URLs.
5. **Images (`0902065b`, 2026-10-08).** Public-domain artworks (Pauwels' Luther, Bruegel's Babel, Amman's 1568 printer) found with `illustration` using Wikimedia `File:` queries. Woodcut-style illustrations generated through `falaw` `generate_image` with a long style prompt (1520s Cranach/Holbein woodcut, cream laid paper, chain lines, ink spread) to avoid the slop look. Charts redrawn with matplotlib in the illustrations' palette (dataviz skill). Each image has alt text and a caption in the markdown title slot.
6. **Tool gaps found, filed, fixed by spawned sessions, then re-tested on this essay (2026-10-08).** `falaw` catalogue (dead Imagen 4 entry, Recraft prompt cap, photoreal default): falaw#76 fixed by falaw#77. SVG saved under `.png` name: falaw#78 fixed by falaw#79. `article` Substack and Medium adapters were stubs: article#3 fixed by article#4 (session `48c0a7c2`, article-substack). The user had told the session to do this: spawn sessions to fix any tool problem, then re-run the step that failed.
7. **Dry run.** `python -m article draft-substack "<path>/essay.md" --dry-run` (and later `article draft-substack --dry-run`): needs no credentials, prints counts (1 footnote, 8 images, 8 captions, 6 headings, title and subtitle from front matter). `0902065b` reported it clean on 2026-10-08 and again on 2026-10-19.
8. **Venue decision (2026-10-18, `0902065b`).** The assistant produced an HTML analysis of how machine-sounding the v1 text was (published via annals, `ductus gauge` plus judgment). The user then chose Substack first, then import to Medium ("Import a story"), and accepted the shortened title "Agile, Reformed" with a subtitle carrying the agentic-AI angle.
9. **De-AI passes v2, v3 (2026-10-18, `0902065b`).** User instruction: rewrite the flagged passages in explicit voices from a pool of authors, with `penlike` models; build missing models; give the rewriter the surrounding context; use `citeget fetch` to gather author texts; rerun ductus until few or none flagged. v2 (PR #34): 29 flagged passages rewritten in the voices of the user's own pre-2023 essay register, Paul Graham, Joel Spolsky, Dan Luu, Maciej Ceglowski, DFW; bold topic sentences removed; 17 long paragraphs split. v3 (PR #35): five rounds with fresh cold-reader subagents (two independent readers from round 4, counting only sentences both flagged). Metric: flagged shapes per 1,000 words, 9.3 to 5.2; the user's own two 2020 essays score 4.95 on the same measure, so it stopped there. Tooling gaps spawned citeget#29, #30, #31, #33 and penlike#3, #4, and `ductus` gained `baseline` and multi-reader consensus (ductus#20, PR #21, v0.0.16).
10. **Logic fixes v3g (2026-10-19, PR #36).** Cut the "quadratically cheaper" aside (arithmetic did not hold), made Royce's "do it twice" agree with the footnote, dropped the Brooks "plan to throw one away" quote (retracted in 1995), two small wording fixes. Three fresh-reader rounds. The user later hand-edited essay.md (the final commit on master is "Clarify analogy of agility to religion").
11. **Credentials (2026-10-26, `0902065b`).** Settings are `SUBSTACK_COOKIES` and `SUBSTACK_PUBLICATION_URL`. The assistant created `~/.config/article/.env` (mode 600, outside both repos because the essays repo is public and does not ignore .env), pre-filled the publication URL, and gave the user a no-echo command so the cookie never appeared in chat: copy the `substack.sid` value from Chrome DevTools (Application, Cookies) and run `printf "SUBSTACK_COOKIES='substack.sid=%s'\n" "$(pbpaste)" >> ~/.config/article/.env`.
12. **The real draft (2026-10-26, `0902065b`).** Exact invocation: `article draft-substack -e ~/.config/article/.env -s ~/.local/share/article/pipeline_state.json "docs/The Agile Religion and the Agentic Reformation/essay.md"`, run from t/essays. Result: unpublished draft https://thorwhalen.substack.com/publish/post/222117873. The `-e` flag selects the env file and `-s` the state file (a state path is needed; the assistant created `~/.local/share/article`).
13. **Verification.** The assistant read the draft back through the API (`make_substack_api(...).get_draft(222117873)`, walking the ProseMirror body) and counted: title, subtitle, 6 headings, 63 paragraphs, 8 images, 8 captions, 1 footnote, `is_published` false. It also ran the package's live test (`tests/test_substack_live.py`, creates and deletes one draft).
14. **What went wrong on the live run, and fixes.** (a) Substack stored every image node as 1456x819 regardless of the real size (portrait 754x972 may look squashed): article#8, fixed by session `812e7c21` (article-substack-dims; PR #9, now measures uploads and writes real width/height). (b) The live test expected the wrong image host (`substackcdn` vs `substack-post-media`), same issue. Neither affected the draft's existence; the assistant told the user to eyeball images in the editor and re-insert any that look off.
15. **Manual steps by the user.** Supply the cookie; open the draft in the Substack editor and check footnote 1 (also on phone), captions, subtitle, opening and ending; press Publish themselves; attach audio by hand (see below). The assistant never has a publish path.
16. **Audio reading (2026-10-26, `0902065b`).** ElevenLabs voice "Thor 01", model `eleven_v3`, 124 performance tags added without changing any word, through `braidio` (the assistant wrote a small md-to-beats converter, filed as reeleehq/braidio#107). Files in `$PP/_agent_work/essays/2026-10-26-agile-reformed-audio/`. Substack's API cannot attach audio, so the user uploads it in the editor's voice-over option. ## What `article` can do today (evidence from the transcripts)

- `article draft-substack <essay.md>` makes an UNPUBLISHED Substack draft through python-substack (`pip install 'article[substack]'`). No publish path exists (`48c0a7c2`, ledger article-substack).
- `--dry-run` works without credentials and prints counts of footnotes, images, captions, headings, latex.
- Keeps footnotes, captions (image title slot: `![alt](img/x.jpg "Caption")`, image alone in its paragraph), headings, uploaded local images, subtitle and title from front matter (else first `# H1`, removed from body).
- Refuses, quoting the line: tables (unless `--tables code`; the update-in-place work in article#7 later added `tables=image`), images sharing a paragraph with text, missing local images, raw HTML blocks, `data:` images, footnote losses.
- Options seen in use: `-e/--env-file`, `-s/--state-file`, `--dry-run`, `--help`. Credentials resolve from the env file or environment.
- Image width/height now set from the uploaded file (article#8, PR #9). Drafts are updated in place on re-run (article#7, from the commit log; not exercised in the `0902065b` transcript).
- Medium adapter sends nothing: it prints the "Import a story" step (import the live Substack URL, canonical applied automatically).
- Not available: audio attachment, reduced display width of images (article#11 open; raw `<img ... width>` blocks are still refused), browser-cookie auto-read (article#10 open; code sits uncommitted on branch `substack-browser-cookies`, blocked by commit denials in session `812e7c21`).
